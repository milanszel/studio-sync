    FL Studio setup guide
    1

    Install the Studio Sync controller

    Already installed? Continue to the next step.

    Installation location
    2

    Pair the MIDI connection

    Open FL Studio → Settings → MIDI.

    Show pairing instructions

    Enable Studio Sync To FL as the input. Choose Studio Sync Transport and set its port to 42.

    Enable Studio Sync From FL as the output and set its port to 42. Leave external clock and master sync off.

    After first installation, restart FL Studio or refresh its MIDI scripts. On Windows, create these two ports in loopMIDI first.
